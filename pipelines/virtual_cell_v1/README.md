# Virtual Cell v1

> 生产状态：已通过 RCEES Slurm Job `9088` 并上线。45,950 个质控后细胞、18/18 位病例/对照供体、14 个评估情境中 2 个通过；165/440 个上游候选有通过情境覆盖。

可配置的供体级疾病单细胞反事实状态基线。管线先按供体×细胞类型做伪汇总，在留一供体评测中验证病例—健康状态轴，再结合已发布虚拟干预分数进行有上限的疾病程序衰减情景投影。默认配置保留类风湿关节炎，其他完整验证疾病通过显式疾病配置运行并写入隔离快照。

只有同时达到留一供体 `AUROC >= 0.65` 与平衡准确率 `>= 0.60` 的细胞类型才进入产品结果；其他细胞类型保留在 `rejected_cell_type_models` 供审计，不参与靶点排序。靶点必须在至少一个通过验证的细胞情境中表达才会被投影。

该版本不是 GEARS/CPA 等生成模型，不声称生成真实扰动后表达矩阵。独立 AUROC/平衡准确率只验证疾病状态轴；干预后变化是带置信区间的可解释情景预测。

产品页展示投影逆转、250 次供体 bootstrap 的 95% 区间、最佳细胞类型、状态轴 AUROC、置信度和投影基因；`20260903-virtual-cell-forest-v1b` 增加了最多 10 个靶点的横向森林图。

# PFD / CAD 制图规范

本文是本项目生成概念 PFD 时的图面约定。目标不是“画得像”，而是让设计人员拿到图后只需要做局部深化，而不是重画。

## 1. 两张图，而不是一张

设计院交付通常把符号说明和工段流程分开：

| 图号 | 内容 | 说明 |
|---|---|---|
| 图 1：图例 | 设备、阀门、仪表、管线符号，图例表，设备一览表，标题栏 | 单独成图，不承载工段流程 |
| 图 2：工段图 | 核心流程、主物料与辅助物料、控制点、物料守恒 | 只保留右下角签名栏 |

工段图上不再堆叠大段文字、设备参数表或说明表。表格统一放到图例图，避免正文比例被表格挤占。

## 2. 图幅、比例与坐标

- 模型空间单位：毫米。
- 常用图幅：A1（841 × 594）或 A2（594 × 420）；默认 A1 横向。
- 图框内边距：左侧 25 mm（装订边），其余 10 mm。
- 常用比例：1:50、1:100。设备尺寸与文字高度按出图比例反算，保证打印后字高 2.5–3.5 mm。
- 图例图与工段图共用同一套图层和符号，不单独维护两套资源。

## 3. 工段图布局

1. 主设备位于图面中部，流程从左到右。
2. **主物料入口贴在左侧图框内边缘，主物料出口贴在右侧图框内边缘**，表示进出车间；不要从设备侧面凭空开始或结束。
3. 辅助物料（蒸汽、冷却水、氮气、清洗液）从上方或下方进入，不穿越主设备。
4. 仪表控制回路画在设备上方或下方，避免与主物料线重叠。
5. 图面只保留右下角签名栏；顶部不再放文本框。
6. 设备位号放在设备正下方；物流标签沿管线放置，避免压住阀门和仪表。

## 4. 设备比例

| 设备 | 建议画法 | 常见错误 |
|---|---|---|
| 精馏塔 | 全图最高设备，高度约为换热器的 3–5 倍，塔径与高度比 1:8–1:15 | 画得比换热器还矮，失去主设备层级 |
| 反应釜 | 釜体 + 封头 + 搅拌电机，高径比 1.2–2.0 | 画成正方形或过扁 |
| 储罐 | 立式或卧式按工艺，立式高径比 2–3 | 与反应釜同高同宽 |
| 换热器 | 管壳式画壳体 + 管程接管，冷凝器按**接管外径**与管线连接 | 管线直接插到壳体中部，不按接管画 |
| 泵 | 泵体 + 电机 + 底座，进出口方向明确 | 只画一个圆圈 |
| 压缩机 | 机体 + 进出口，必要时加缓冲罐 | 与泵混用同一符号 |
| 阀门 | 阀体宽高比约 1:1，手轮/执行机构完整 | 画成矮胖矩形，执行机构与阀体脱开 |
| 气动阀 | 阀体、阀杆、执行器、气源接口**闭合连接** | 执行器悬空，阀杆断开 |
| 仪表 | 圆圈 + 位号，控制阀与检测点用信号线连接 | 只写文字，没有检测点 |

设备尺寸以同一基准缩放：塔、储罐等主设备优先保证视觉层级，不允许辅助设备比主设备更醒目。

## 5. 线型与线宽

| 图层 | 内容 | 线宽 | 线型 |
|---|---|---|---|
| `PFD-MAIN` | 主物料 | 0.50 mm | 实线 |
| `PFD-AUX` | 辅助物料 | 0.17 mm（主物料的 1/3） | 实线 |
| `PFD-UTIL` | 公用工程 | 0.18 mm | 实线 |
| `PFD-INST` | 仪表信号 | 0.18 mm | 细实线或点划线 |
| `PFD-EQUIP` | 设备轮廓 | 0.35 mm | 实线 |
| `PFD-DIM` | 尺寸与引出线 | 0.13 mm | 细实线 |
| `PFD-TEXT` | 文字 | 0.18 mm | — |
| `PFD-FRAME` | 图框与标题栏 | 0.35 / 0.50 mm | 实线 |

辅助物料线必须是**实线**，不能用虚线；虚线只用于隐藏轮廓、假想线或特殊说明。

## 6. 图层与颜色

| 图层 | 颜色 | 用途 |
|---|---|---|
| `PFD-EQUIP` | 白/黑（按背景） | 设备轮廓、支座 |
| `PFD-MAIN` | 红 | 主物料 |
| `PFD-AUX` | 青 | 辅助物料 |
| `PFD-UTIL` | 蓝 | 蒸汽、冷却水、氮气 |
| `PFD-INST` | 黄 | 仪表与信号 |
| `PFD-TEXT` | 白/黑 | 位号、物流标签 |
| `PFD-FRAME` | 白/黑 | 图框、标题栏 |
| `PFD-DIM` | 绿 | 尺寸标注 |

导出 DXF 时写入对应图层名和颜色索引；不要把所有实体放在 `0` 层。

## 7. 物料守恒

主物料从左侧进入、右侧离开时，入口与出口流量必须在图上同时可见。

示例：

```
主物料入口 500 kg/h  ──►  [ R-101 ] ──►  主物料出口 450 kg/h
                                      │
                                      ├──► 废水 30 kg/h
                                      └──► 蒸汽夹带 20 kg/h
```

规则：

1. 入口与出口标签都带单位，默认 `kg/h`。
2. 差额必须显式画出分支，不能只在备注里写“损耗”。
3. 差额去向包括：排污、母液、蒸汽、副产、采样、泄漏/未知损耗。
4. 无法确定去向时，标注“待确认 50 kg/h”，并在图例页的物料平衡表中列出。
5. 生成图纸前执行守恒校验；不守恒时给出黄色警告，但不阻止导出草稿。

## 8. 物流标注

- 主物料：`名称 + 流量 + 温度/压力（可选）`，例如 `反应液 500 kg/h · 37 °C`。
- 辅助物料：`名称 + 流量`，例如 `冷却水 12 m³/h`。
- 仪表：`位号 + 功能`，例如 `TIC-101 反应温度控制`。
- 箭头方向与流向一致；进出车间的管线在边框处加箭头和“进车间 / 出车间”标识。

## 9. 图例图内容

图例图至少包含：

- 设备符号表：反应器、塔、换热器、储罐、泵、压缩机、离心机、干燥器。
- 阀门符号表：闸阀、截止阀、球阀、蝶阀、止回阀、调节阀、气动阀。
- 仪表符号表：温度、压力、流量、液位、分析。
- 管线符号表：主物料、辅助物料、公用工程、仪表信号。
- 设备一览表：位号、名称、数量、主要参数。
- 物料平衡表：入口、出口、差额、去向。
- 标题栏与修订记录。

## 10. 出图前检查清单

- [ ] 主物料入口在左、出口在右，均顶到图框内边缘。
- [ ] 入口与出口流量同时标注，差额有去向。
- [ ] 精馏塔是全图最高设备，储罐高度合理。
- [ ] 阀门宽高比正常，气动执行器与阀体闭合。
- [ ] 冷凝器与管线按接管外径连接。
- [ ] 辅助物料为实线，线宽约为主物料的 1/3。
- [ ] 工段图没有大段文字表格，只保留右下角签名栏。
- [ ] 所有实体在正确图层，颜色和线型可被 AutoCAD 识别。
- [ ] SVG 预览与 DXF 导出一致。

## 11. 输入方式

当前支持：

1. **结构化节点编辑**：在画布上添加设备、连线和参数。
2. **文字工艺描述**：粘贴工艺说明，由模型抽取设备、物流和参数。
3. **图片/截图**：先 OCR，再结合文本模型抽取流程。
4. **表格/设备清单**：识别位号、名称、流量和条件。

推荐链路是“文本/图片 → 流程模拟或结构化流程 → PFD → CAD”，而不是让模型直接画最终施工图。模型负责抽取和起草，工程师负责确认物料衡算、设备选型和图面深化。

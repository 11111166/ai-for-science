## 本地演示

```bash
# 终端 1
cd services/api
uvicorn app.main:app --reload --port 8000

# 终端 2
npm run dev:web

# 终端 3：载入演示项目
cd services/api
python seed_local_demo.py
```

浏览器打开 <http://localhost:3000/login>，注册本地账号，进入“L-苯丙氨酸 酶法转化—结晶精制 工艺开发演示”。

## 建议的体验路径

1. 进入项目 → 工艺开发 → PFD 工作区。
2. 在“工艺信息接入”中粘贴下面的示例文字，点击识别并生成草稿。
3. 在画布上调整设备位号、温度和流量，观察主物料线、辅助物料线和物料守恒提示。
4. 切换到“图例”页检查符号表与标题栏，再回到“工段图”页。
5. 导出 SVG 与 DXF，用 AutoCAD 或 LibreCAD 打开检查图层和线型。

## 示例输入

```text
500 kg/h 的 L-苯丙氨酸钠盐水溶液从车间左侧进入反应工段。
反应釜 R-101 内加入固定化酶，控制 37 °C、pH 8.0，停留 4 h。
反应液经泵 P-101 送入板式换热器 E-101，冷却到 20 °C。
冷却液进入结晶釜 C-101，加入晶种，结晶 6 h。
晶浆送入离心机 S-101，得到湿晶体 420 kg/h 和母液 80 kg/h。
湿晶体进入干燥器 D-101，得到成品 405 kg/h。
离心母液 80 kg/h 返回反应釜；另有 15 kg/h 排入废水收集罐 T-101。
蒸汽冷凝水 50 kg/h 送至公用工程站。
```

系统会检查 500 kg/h 入口与出口之间的差额，并要求补充去向说明。
